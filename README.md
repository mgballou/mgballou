## Matthew Ballou

Software engineer — Laravel and PHP, TypeScript and React.

🩺 **[suivre](https://github.com/mgballou/suivre)** — A food and symptom journal that correlates diet and lifestyle with inflammatory flares on a lag. Laravel 13, Inertia + React 19, PostgreSQL, and a [decision log](https://github.com/mgballou/suivre/blob/main/docs/decisions/decision-log.md) with the reasoning behind every call, including the reversals.

🧾 **[pacioli](https://github.com/mgballou/pacioli)** — A double-entry ledger service in Go where the balance rule is a Postgres constraint trigger, so a migration or a psql session cannot write around it. The API is the standard library, and 65 negative controls break the code on purpose to prove each test turns red.

👑 **[dread-majesty](https://github.com/mgballou/dread-majesty)** — An incremental game where each tier of production pays out in the one below it. The engine is pure TypeScript: no DOM, no React, no I/O, no clock. [Play it](https://dreadmajesty.netlify.app).

🎧 **[playlist-me-3](https://github.com/mgballou/playlist-me-3)** — Spotify playlists built from the sources and exclusions you pick, not your whole listening history. Clone it and it runs with no credentials.

⚔️ **[someones-pc-teambuilder](https://github.com/mgballou/someones-pc-teambuilder)** — Competitive Pokémon team planning: damage, speed tiers, coverage and legality. Gen 9 damage is integer-exact and returns all sixteen rolls.

🔬 **[suivre-insights-poc](https://github.com/mgballou/suivre-insights-poc)** — A simulation study asking whether Suivre's core insight really finds a dietary trigger. It does, but not reliably enough to show as a ranked list — so the app doesn't.
